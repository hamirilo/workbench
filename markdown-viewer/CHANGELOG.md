# Changelog

## 0.1.0

### 変更点

- 最初の版です。Markdown のファイルを開いて読みやすく表示します（見るだけで、ファイルは書き換えません）
- 表・チェックリスト・取り消し線・脚注など GitHub と同じ書き方に対応し、コードは言語ごとに色分けします
- 左の目次から見出しへ移れます。いま読んでいる見出しが目次で分かります
- ほかのエディタでファイルを保存すると、表示も自動で新しくなります
- .md のファイルをダブルクリックして開けます（インストールすると関連付けの候補になります）

### ダウンロード

- Windows：`Markdown_Viewer_0.1.0_x64-setup.exe`
- macOS（Apple Silicon）：`Markdown_Viewer_0.1.0_aarch64.dmg`

### 注意

- Apple や Microsoft の署名をしていないので、初回だけ警告が出ます（README「インストール」）
